Upload CSV File

How to Use

Upload a CSV file with housing data to get predicted house prices.

Required Columns

  • MedInc: Average income in the area
  • HouseAge: Age of houses (in years)
  • AveRooms: Average number of rooms per house
  • AveBedrms: Average number of bedrooms
  • Population: Total population in the area
  • AveOccup: Average number of people per house
  • Latitude: Location coordinate (32–42)
  • Longitude: Location coordinate (-125 to -114)

Important Notes

  • Column names must match exactly (case-sensitive).
  • All values should be numeric.
  • The file must not be empty.
  • After upload, a new CSV with predicted prices will be downloaded.
