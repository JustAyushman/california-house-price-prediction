About This Project

This project predicts California house prices using a Machine Learning model served through a FastAPI backend with an interactive frontend.

Dataset

The project uses the California Housing Dataset, which contains 20,640 rows of housing data collected from the 1990 census.

Features Used

  • MedInc: Median income in the area
  • HouseAge: Age of houses
  • AveRooms: Average rooms per house
  • AveBedrms: Average bedrooms
  • Population: Area population
  • AveOccup: People per household
  • Latitude & Longitude: Location coordinates

The target variable is MedHouseValue, which represents house price in units of $100,000.

Machine Learning Model

  • Model: Random Forest Regressor
  • Library: Scikit-Learn
  • Problem Type: Regression

The model predicts house prices based on patterns in income, housing characteristics, and geographic location.

Average prediction error is approximately $39,000.

Backend (FastAPI)

  • Framework: FastAPI
  • Model loaded using joblib
  • Data processed using Pandas
  • Input validation using Pydantic

API Endpoints

  • /predict: Predict price for single input
  • /predict-file: Predict prices for CSV upload
  • /health: Check API and model status

Frontend

  • Built with HTML, CSS, JavaScript
  • Manual input prediction form
  • CSV upload for bulk prediction
  • Styled with a responsive glassmorphism UI

How It Works

  • 1. User enters data or uploads CSV
  • 2. Data is sent to FastAPI backend
  • 3. Backend validates and processes input
  • 4. Model predicts house prices
  • 5. Results returned as JSON or CSV

Technologies Used

  • Python
  • FastAPI
  • Scikit-Learn
  • Pandas
  • Joblib
  • HTML, CSS, JavaScript
